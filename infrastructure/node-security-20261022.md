# Node security runtime patch, 22 October 2026

George authorised patching the VPS, then Mac runtimes and repository build configurations against the 21 October Node security release. The release floors are 22.23.4, 24.22.1 and 26.12.1. Separately installed Undici must also use the fixed release for its branch: 6.29.1, 7.30.1 or 8.12.2.

The eight affected host containers use tested images derived from their exact previous application images. Application versions and data volumes were preserved. Cal.com moved from Node 20 to Node 22.23.4, including native module compatibility and read-only login/session checks. The host Cyrus service and the Codex guest SDK were upgraded to Node 22.23.4. The E2B dashboard, Open Inspect control plane and Nomad logs API also run 22.23.4.

The Compose overrides beside the product declarations select the tested local images, set `pull_policy: never` and disable Watchtower for those services. Keep the overrides when deploying from source. Other automatic updates retain their existing settings. Do not remove an override or resume a vendor image until its actual Node binary and separately bundled Undici have been checked. These images currently exist on the VPS Docker engine. A new host needs a deliberate image rebuild or transfer before those declarations can run.

The Run Buddy Nomad declaration selects the tested runner image. PATH Node and both bundled Node 24 executables are fixed, persistent externals are reconciled on startup and retired Node 20 executables are removed. Runner self-updates are disabled to prevent an upstream distribution overwriting the patched bundled executables. This creates an explicit manual runner update obligation: check the repository's authenticated runner-downloads API and deploy a compatible runner within GitHub's update deadline. The application remains runner 2.337.0, the version offered by that API during this change. Do not restart the former Compose or systemd runner owners.

The existing Usual Suspects CI image aliases v1, v2 and v3 now resolve to derived images with Node 24.22.1 and npm's Undici 6.29.1. Existing browser and Bun layers were preserved. The current source CI Dockerfile uses the fixed download and checksum and backports npm's Undici for future builds. A retained GitLab build container had already exited on 14 October and was not restarted or cancelled.

Protected rollback images, configuration preimages, build inputs and deployment receipts remain on each affected VPS host or guest under `/var/lib/onestack-maintenance/node-security-20261022/`. Management credentials and production payloads stay remote. The local sanitised audit, change register and verification receipts are under `/Users/curiousgeorge/workspace/security-audits/node-2026-10-22/`. Keep failed staging and automatic rollback receipts as part of the record.

Live validation passed runtime version, Brotli/gzip, DNS rejection, TLS identity and loopback HTTP checks. The public endpoint suite passed 19 checks, Cal.com passed 14 read-only checks and the Nomad logs API passed its five existing authorisation and method checks. These checks do not establish every authenticated user workflow. No mail, booking, bidding, client-data mutation or database migration was used as a test. The temporary maintenance lease was removed. The pre-existing backup capacity failure remains a separate unresolved issue.
